Mercado Pago

Checkout Pro para recursos digitales. El pago aprobado y verificado habilita el archivo automáticamente.

  1. Ingresá con la cuenta que va a recibir los pagos y creá una aplicación de Checkout Pro en Tus integraciones.
  2. Obtené el Access Token de prueba, el ID de la cuenta vendedora y la clave secreta de Webhooks.
  3. Configurá el evento Pagos y esta URL: {{ site_url }}/pagos/mercadopago/webhook.
  4. Cargá las claves en el servidor con python -m deploy.configure_payments y reiniciá el sitio.
  5. Verificá la conexión, realizá una compra de prueba y comprobá la habilitación del material. Después activá las credenciales de producción.

Los pedidos físicos se confirman por transferencia y su envío se coordina por WhatsApp.

MiCorreo · Correo Argentino

Origen actual: {{ origin or 'Sin configurar' }} · Bahía Blanca. Cotización por código postal a domicilio o sucursal, según las opciones que devuelva Correo.

  1. Creá o usá tu cuenta de MiCorreo y solicitá a Correo Argentino el acceso a su API MiCorreo para tu tienda.
  2. Necesitamos usuario y contraseña de la API, Customer ID y ambiente (prueba o producción). El acceso de la web MiCorreo por sí solo no habilita la API.
  3. Cargá los datos en el servidor con python -m deploy.configure_shipping y reiniciá el sitio.
  4. Completá el peso en gramos y las tres medidas en centímetros de cada material embalado.
  5. Agregá un material al carrito y probá distintos códigos postales antes de ofrecer la cotización al público.

Preparación aproximada: {{ store.preparation_days }} días desde el pago, más el traslado. La cotización es orientativa; el despacho y el pago del envío se coordinan manualmente por WhatsApp.
